    Open and Save

    The buttons for opening and saving are on the left panel:

    Open

    Two types of files can be opened: image file and centerline file. To open a file, click the button "Open".

    An image file is a NIfTI file (extension name: .nii or .nii.gz) or a TIFF file (extension name: .tif).

    A centerline file is a YAML file (extension name: .yaml or .yml) or an SWC file (extension name: .swc). The YAML file should follow VesselVoyager's centerline format; the SWC file should follow iCafe's centerline format.

    The opened file paths are displayed in the upper center of the window, like this:

    Save

    To save the centerline result to the currently opened centerline file, click the button "Save". The hotkey is Ctrl + S.

    To save the centerline result to another file, click the button "Save As", then a prompt window will ask for a file path to save the result, and once saving is finished, the opened file path will be changed into the new path.

    Cannot save to a SWC file

    If the opened centerline file is an SWC file, then the button "Save" will be disabled (cannot be clicked). This is because the software always saves the result into a YAML file.

    Changelog

    V1.5.1

    Bug fix:

    • Fixed the bug that the software cannot read the cross-sectional image folder if there exist two image sequences where one name is xxx and the other name also ends with xxx.

    V1.5.0

    Functionality:

    • Undo and redo. Use Ctrl+Z or Ctrl+Y to undo or redo an operation. The operation can be editing a contour or shifting a slice. "Apply Shift" can also be undone or redone.
    • Load contours from a segmentation file. Click the menubar, "Contour" -> "Load from Seg" to select the segmentation file to load. After loading, one can optionally clean all previous contours of a loaded contour type in the prompt window.
    • Mark the reference slice. By default the first slice is the reference slice. To set another slice as the reference slice, go to that slice, then click the menubar, "Show" -> "Set Ref. Slice". The reference slice has a relative index of 0, and other slices have relative indices of positive or negative numbers, depending on the relative location to the reference slice. The relative index is shown in a textbox of the left panel, next to the slice index textbox. One can type a number in the text box to quickly go to the slice with the corresponding relative index.
    • Hotkey settings. Click the menubar, "Settings" -> "Hotkeys" to check all hotkeys. One can customize the hotkeys in the prompt window. The hotkeys will be saved for each Windows user account.
    • Add two endpoints handles to the line segment in the cross-sectional slice window in the MPR mode to enable moving the line segment.

    UI:

    • When the mouse hovers over a contour or its key point, the corresponding item will be highlighted to indicate that it can be clicked.
    • Selected text box will be highlighted with an orange border.
    • Click the menubar, "Help"->"User Manual" to see software instructions.

    Bug fixes:

    • Fix the bug that the intensity information in the lower right corner of the cross-sectional image window does not account for the image offset.
    • Fix the bug that the shown slice is incorrect when the number entered into the slice index textbox is smaller than 1 or larger than the number of slices.
    • Fix the bug that visualizing 3D centerlines requires a 3D image file named exactly as "TOF.nii.gz". Now any ".nii.gz" file in the parent folder of the "xsec" folder can be detected.
    • Fix the bug that the contour width will become smaller after one clicks outside the contour on the image.
    • Fix the bug that when one starts to drag a contour key point and the initial speed is too large, dragging will fail.
    • Fix the bug that when one starts to drag a contour key point, there is a delay before the point starts moving.

    V1.4.1

    Bug fix:

    • Fix the bug that if some slices has no lumen and outer wall contours, when exporting report the calculation of area_ce fails.

    V1.4.0

    Functionality

    • Apply the shift (a.k.a. offset, or manual registration) of current slice of an image sequence to other slices (user specified), by menubar, Show-Apply Shift.
    • When rotating the line segment on the cross-sectional window to change the MPR view, the MPR views of all image sequences are synchronized. In other words, the line segments for rotation behave in the same way when each of them is rotated.
    • The number of key points of the contours predicted by AI is reduced to a half of the previous number. Therefore, users can modify the contours more conveniently.

    UI

    • Show the axial, sagittal, coronal views of original 3D images (if exists) in a separate tab on the left side. The views correspond to the spatial location (in original space) of currently shown cross-sectional slices.
    • When extracting cross-sections from a VesselVoyager folder, users can select image sequences and specify the height and width of the cross-sections (200 by default).
    • Open a MOCHA folder or a VesselVoyager folder using the same menubar button: File-Open Folder.

    Bug fix:

    • The MPR views now respect the shifts of different slices. (Previously, the MPR views were based only on the nii images, and did not consider manual registration via the Shift button.)
    • When extracting cross-sections from a VesselVoyager folder, the points of interpolated centerlines now have (nearly) equal distance (1 pixel).

    V1.3.1

    Functionality

    • Visualize VesselVoyager centerlines in 3D.

    V1.3.0

    Functionality:

    • Calculate and visualize contrast enhancement map.
    • Show or hide sequences by clicking menubar, Show-Sequences-{sequence_name}.
    • Press shift+Q or shift+E to change the shown slice directly to the last or next slice that contains contours of shown contour types.
    • Add a button "Grid". When it is activated, a grid of dashed lines appears on each cross-sectional image window to assist in viewing the degree of alignment between image sequences.
    • Press = or - keys to expand or shrink a selected contour.
    • Add a button "default" to reset the intensity window of each sequence to the the range from 1st to 99th percentile of the intensity distribution.
    • Support ctrl+s to save results, which has the same effect as clicking the save button.
    • Click on an MPR image to quickly change the shown cross-sectional slice.

    UI:

    • When hovering the mouse over a cross-sectional image, show the pixel index and intensity at two corners of the image window.

    Bug fix:

    • After opening another case, several functions (e.g., AI prediction) will behave strangely.
    • After deleting a wall contour in a slice and then doing AI wall segmentation, the prediction does not appear for the slice.

    V1.2.1

    Bug fix:

    • Allows image spacings and sizes different from what the AI models were trained on. An automated rescaling and resizing will be performed in pre- and post-processing.

    Misc:

    • Support packaging the software as a single file rather than a folder.

    V1.2.0

    Functionality:

    • Add a toggle button called "Pan" to activate or deactivate panning/zooming images by mouse dragging or scrolling.
    • Support moving selected contours by pressing arrow keys.
    • Add a prompt window when starting AI lumen/wall segmentation, within which users can:
      • Select a sequence to run the AI (previously "S101" will be automatically used).
      • Check a checkbox to perform AI only for those slices with no lumen or wall contour. The checkbox is checked by default.
    • Add a toggle button called "Drag Control" above the intensity window table. When it is enabled, dragging mouse on images can adjust window level and width.

    UI:

    • Adjust column margin in tables to make them more compact
    • Show tips when hovering over the Shift, MPR, or Pan buttons.
    • Add text instructions in two prompt windows:
      • Selecting sequences to show after opening a cross-sectional (MOCHA) folder,
      • Selecting vessel types to extract cross-sections after opening a VesselVoyager folder.
    • Adjust positions of some buttons.

    V1.1.4

    Functionality:

    • Support selecting contour keypoints by clicking, and deleting selected keypoints by pressing the delete key.
    • Support adding keypoints to an existing contour by ctrl+clicking on the contour.

    V1.1.3

    UI:

    • Heights of the cross-sectional and MPR windows become adjustable through a vertical splitter.
    • In the left panel, the widgets below the buttons now stretch over the entire vertical space.

    Functionality:

    • Add a horizontal line on each MPR window to show the location corresponding to the cross-sectional slice.
    • Add linear interpolation mode to smooth image, which can be enable through the menubar, Settings/Smooth Image.
    • Support copying and pasting selected contours using conventional hot keys.

    Bug fix:

    • Fix the bug that when MRP view is enable, the MPR image does not correspond to the rotation line on the cross-sectional slice (it corresponds to the line obtained by flipping the rotation line along the diagonal).
    • Fix the but that after selecting contours and moving to another slice, the selected contours stored in the background are not removed.

    V1.1.2

    Bug fixes:

    • Fix the bug that the software fails to open an folder if the nii files are named as "xsec_{whatever}_{seq}.nii.gz“ rather than "xsec_{seq}.nii.gz".

    V1.1.0

    Functionality:

    • Support AI prediction for lumen and outer wall.

    V1.0.1

    Bug fixes:

    • When a data folder has already been opened, the user now can open another folder. Previously nothing would happen after the user do this.

    Functionality:

    • Support multiple project (QVJ) files in the same folder. A pop-up window will ask the user to select one QVJ to read contours.

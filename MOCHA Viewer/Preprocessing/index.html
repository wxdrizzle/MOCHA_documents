    Preprocessing

    Assume you start with raw DICOM data of multiple image sequences. This page provides instructions about necessary initial steps to preprocess the raw data.

    To start, load the raw data by click the button File → Open Raw Data. A prompt window will ask you to select the folder that contains those DICOM files.

    Sequence Selection

    Once the folder is selected, the software starts to read the DICOMs and analyze what image sequences within.

    A prompt window (example shown below) will display the sequence information.

    On the left panel, there is a table (①). Each row corresponds to one image sequence.

    • Column 1 (Include): whether you want to include this image sequence for further processing and analysis. By default, all sequences are included. You can uncheck the checkboxes to exclude specific sequences.
    • Column 2 (Original Name): the original sequence names. This name is stored in the meta data of DICOM files. If you open the folder using RadiAnt, you will see the same name appears on the left panel of RadiAnt. The text in this column is not modifiable.
    • Column 3 (New Name): The new names you want to use for each image sequence. Double click to change the text. By default, the names are the same as the original names (except that "_" in the original name will be replaced by "-"). But changing the names makes further analysis clearer, e.g., you may want to change the name of sequence 1, 2, 3 to "pre-T1", "post-T1", and "TOF", respectively.

    The right panel displays the image of currently selected sequence. You can change the display to another sequence by clicking its original name on the left panel. This image display helps you better identify what this sequence is. There is a small vertical line (②) below the image. Dragging it will change the slice displayed.

    Once you have excluded sequences you don't need, and specify new names for the sequences you want to include, click OK. A prompt window will ask you to specify a patient folder to store the results. Usually this folder should be an empty folder (you may just create an empty folder in the prompt window) for this patient. All further analysis of the patient will be performed in this folder, including centerline tracing, MPR extraction, etc.

    Once the patient folder is selected and the processing is done, you will see each image sequence is stored as an nii file in the folder, whose name is the new name you have specified (example shown below).

    Image Registration

    Select Reference and Moving Sequences

    Once the processing is done (the nii files are generated), the next step is image registration. A prompt window (example shown below) will automatically show to ask for registration information. If you cancelled this step by mistake or you just want to do image registration again for some specific image sequences, you can also trigger this prompt window by clicking the menubar, Preprocess → Registration.

    Image registration is performed in a pairwise manner, namely each registration involves a reference (fixed) sequence and a moving sequence, and the registration will spatially align the moving sequence to the reference sequence by calculating a (rigid) spatial transformation. Specifying the reference and moving sequences is done by checking the checkboxes in column 2 and 3, respectively. Note that only one sequence can be selected as the reference, and all selected moving sequences will be registered to the reference.

    Note

    In practice, if we have \(N\) sequences, we usually need to do \(N-1\) registrations. It is recommended to select TOF MRA (if available) as the reference sequence, and other \(N-1\) sequences as the moving sequences.

    The column 4 (Transform Same As) is designed for very special scenarios where some sequences may initially be registered during imaging. For example, the i2 and SNAP sequences in one single SNAP scan are usually assumed to be well registered because they are imaged together. In this case, one may want to select i2 as a moving image, and register it to the reference sequence TOF. For the other sequence SNAP, if we also select it as a moving sequence, then a separate registration will be performed between SNAP and TOF, which is not desirable. Instead, we may want to use the registration result of i2-to-TOF for SNAP-to-TOF, so that i2 and SNAP are still well registered after i2 is registered to to TOF. To this end, we need to select TOF as the reference sequence, i2 as the only one moving sequence, and then for SNAP, we select "i2" in the column 4, as shown below. This means "the spatial transformation of SNAP should be the same as the spatial transformation of i2".

    Set Initial Alignment

    Once reference and moving sequences are selected, the next prompt window (shown below) will ask you to specify initial alignment parameters. The goal of this step is to specify a 3D point (spatial location) in each sequence, so that the selected locations of different sequences will be spatially aligned before the registration is started. This initial alignment is very important. It provides a rough initial registration effect so the following iterative automated registration is easier. If initial alignment is bad (e.g., the eye of one sequence is aligned with the circle of Willis of another sequence), then the following automated registration may fail.

    The prompt window (example above) is divided into several sub-windows, each of which corresponds to the reference sequence or a moving sequence. The components in each sub-window includes:

    • ① Sequence name
    • ② A red crosshair indicates the point (3D spatial location) for this sequence.
    • ③ The coordinates of the point.
    • ④ A vertical line. Drag it to change the displayed 2D slice. The red crosshair appears only if the 3D point is located in the displayed 2D slice.
    • ⑤ If the displayed slice is not the one that contains the 3D point, then clicking this button to quickly change to the slice of the 3D point.
    • ⑥ Reset the 3D point to the default location, i.e., the center of the 3D image.

    You can zoom in or out by scrolling up or down. You can click on any location of the image to change the 3D point to the clicked location.

    It is recommended to change the 3D points for each sequence so these points are roughly at the same anatomical structure of the patient brain. A recommended structure is the tortuous part of the right ICA (because it is easy to find), as shown below.

    Automated Registration

    Once the points are good, click OK to proceed. The automated registration will start. It is an iterative method. A prompt window with a progress bar will show the registration progress:

    Note that registration is sequentially performed for each moving sequence, so you may see a prompt window disappears (registration finished for current moving sequence) and another one appears (registration started for next moving sequence). This procedure may take a few minutes.

    Once registration is done for all moving sequences, the results will be stored as txt files in the same patient folder:

    In the example above, since we have two moving sequences (pre-T1 and post-T1), there are two txt files storing the registration results for them separately. The name of the registration file indicates the moving sequence and reference sequence.

    Once registration is finished, the following steps include

    1. Use VesselVoyager to trace centerlines on TOF, and generate centerline.yaml as the result. This is detailed in the VesselVoyager document.
    2. Use MOCHA to extract the MPR views for the sequences based on the centerline files and the registration files. To read the details, go to "Patient Folder Reading" on the left table of content of this webpage, then go to the section "3D Image Folder".

    Modify Centerline Locations

    Hover and select

    Since each centerline contains two parts: a curve and several key points, the mouse hovering and selecting also work for them separately.

    Since a key point is usually very close to a location on the curve, the software need to know whether you want to hover over the key point or the curve, if the mouse is around the key point. The button "Selection Priority" on the left panel is for this purpose:

    By default, the priority of key point is larger than the curve. In this mode, if the mouse is close to both a key point and a curve, then the key point will be hovered. In this mode, the button is in blue (as shown above), and the text is "Ｏ > ～", where "Ｏ" means "key points", "～" means "curve", and ">" means "larger than".

    The other mode is that the priority of curve is larger than key points. In this mode, if the mouse is close to both a key point and a curve, then the curve will be hovered. In this mode, the button is in orange (as shown below), and the text is "～ > Ｏ".

    To switch between the two modes, click the button or press Ctrl + D.

    Hover over a centerline key point

    If a key point is hovered, the point will be highlighted in a relatively bright white color:

    Select centerline key points

    If a key point is hovered, left-click to select it. Other things that are previously selected will be deselected at the same time. If only one key point is selected, press - or = to switch the selection to the previous or next key point of the same centerline.

    To select multiple key points one by one, press and hold Ctrl , then hover over a key point and left-click. This is the same as selecting multiple files. During this procedure, if you left-click on a selected key point, it will be deselected.

    To select multiple key points, you can also draw a region. Before doing this, first make sure the selection priority of key points is larger than curve (the button "Selection Priority" should be in blue). Press and hold Ctrl, then drag the mouse. This will draw a region based on the mouse trajectory, and select all the key points inside the region:

    The selected key points will be shown in a very bright white color (brighter than hovered key point).

    Hover over a centerline curve

    If a curve is hovered, the curve will be highlighted in a relatively bright white color, and the specific hovered location on the curve will be shown as a red point (smaller than centerline key points).

    Sometimes multiple centerlines are close to each other, and you may find the hovered location or hovered centerline curve is not what you want. Then you can press Shift + Space to change the hovered location to another centerline location that is close to the mouse. You can confirm the change by the red point location or the highlighted curve.

    Select centerline curves

    If a centerline curve is hovered, left-click to select it. Other things that are previously selected will be deselected at the same time.

    To select multiple centerline curves one by one, press and hold Ctrl , then hover over a curve and left-click. This is the same as selecting multiple files. During this procedure, if you left-click on a selected curve, it will be deselected.

    To select multiple curves, you can also draw a region. Before doing this, first make sure the selection priority of curve is larger than key points (the button "Selection Priority" should be in orange). Press and hold Ctrl, then drag the mouse. This will draw a region based on the mouse trajectory, and select all the curves inside the region:

    The selected curves will be shown in a very bright white color (brighter than hovered curve).

    Cross-sectional window

    The cross-sectional window is shown on the left panel. If a key point is selected, the cross-sectional image, which goes through this point and is perpendicular to the centerline curve that contains the point, will be shown in the window:

    A semi-transparent blue square will be shown in the 3D window to indicate the cross-sectional plane.

    In the cross-sectional window, if the mouse is outside the window, then a red crosshair will be shown to indicate the center of the cross-section (corresponding to the intersection point of the centerline curve and the cross-section). You can use it to quickly check whether the centerline location is at the lumen center.

    In the cross-sectional window, if the mouse is inside the window, then a blue crosshair and a blue circle will be shown to indicate the mouse position. This is helpful for moving the selected key point, which will be explained in the following section.

    If no key point is selected, then the cross-section is for the hovered key point or hovered centerline curve location (indicated by a red point, as mentioned before). If multiple key points are selected, then no cross-section will be shown.

    Move a key point

    To move a key point to a new location, first you need to select it and only it. Then, there are two ways to change its location.

    The first way is to use the cross-sectional window. This way is useful if you notice that a key point is not at the lumen center and want to move it to the center.

    1. Move the mouse to the desired location on the cross-sectional image.
    2. If the lumen is too small or too large, you can zoom in/out by scrolling up/down to make lumen boundary better match the blue circle.
    3. If the lumen is too large such that the cross-section only contains part of the lumen, you can click the button "+" in the upper right corner of the cross-sectional window to increase its coverage; similarly, click the button "-" to decrease the coverage.
    4. Shift + click. The selected key point will be moved to the 3D location that corresponds to the clicked 2D location of the cross-section.

    The blue cross-sectional plane in the 3D window and the 2D image in the cross-sectional window will be both updated immediately to reflect the key point location change.

    The second way is to use casted ray. This way is useful if the key point is far away from the lumen, such that the cross-sectional image does not even contain the lumen.

    1. Select only the key point.
    2. Shift + click on the location you want the key point to move to in the 3D window.
    3. Rotate the 3D image to observe the vessel from another direction, then you will see a cyan straight line that goes through the key point's new location. This line is the ray casted from the 2D mouse clicking location on the screen toward the 3D image. The ray is perpendicular to the screen. The location on the ray with the max image intensity is automatically calculated as the new key point location. By observing the vessel from another direction, you can determine whether the max intensity location on the casted ray is the location (lumen center) you want.
    4. If the new location of max intensity is still not what you want, then press and hold Shift, and move the mouse around the casted ray. The hovered location on the ray will be indicated by a small white point.
    5. Shift + click to change the key point location to the hovered location on the ray.

    Therefore, by two clicks plus a dragging, you can move a key point to any 3D location you want in the 3D window. Note that click other places without dragging will make the ray disappear.

    Add a new key point on a centerline

    You can add a new key point to an existing centerline. This is useful if you find the key point spacing is too large such that the centerline shape does not match the vessel shape correctly.

    1. Hover a centerline curve, such that a red point is shown to indicate the hovered location on the curve.
    2. Shift + A to add a key point at the hovered location.

    Not applicable for non-key-point-based centerlines

    If the centerline is not key-point-based, then you cannot add a new key point. This is because in this situation, the centerline is determined by dense point locations rather than interpolation based on key points, and each centerline only have two fake key points at the two endpoints. This will happen if the opened file is an SWC file, or a YAML file that was saved directly using an SWC file's centerline information. The function of converting such centerlines to key-point-based will be implemented in the future.

    Delete key points

    You can delete key points of existing centerlines. This is useful if you find the key point spacing is too small such that the centerline shape is weird (caused by improper interpolation), or you have multiple centerlines share one key point (e.g., the bifurcation point) and you want to disconnect these centerlines.

    1. Select the key points you want to delete.
    2. Press Del or Backspace.

    Alternatively, you can right-click a hovered key point to delete it.

    Note that if after deleting, a centerline only has one key point, then that key point and the entire centerline will also be deleted. If a deleted key point is shared by multiple centerlines, then the key point will be deleted for all those centerlines.

    Split a centerline

    You can split a centerline into two centerlines that share a key point at the split location. This is useful if you find the centerline actually contains two arteries, and you want to label two types. It is also useful if you want to change a centerline into two separate centerlines that does not share a key point at the split location, such that you can modify them separately (just delete the key point at the split location after splitting).

    1. Hover a centerline curve , such that a red point is shown to indicate the hovered location on the curve.
    2. Shift + S to split the centerline into two. A new key point will be added at the split location and shared by the two centerlines.

    Add new centerlines

    To create new centerlines, first click the button "Add Points" on the left panel to enter the add-point mode. The hotkey is Ctrl + +a+.

    Then, click the locations that you want to add key points at in the 3D window, following the order from one endpoint to the other endpoint of the centerline to create. the newly added key points will be shown in white.

    You can also select existing key points in the add-point mode if you want the new centerline to be connected to existing centerlines.

    If you click a location by mistake, you can undo the clicking by Ctrl + Z.

    Then exist the add-point mode by clicking the button or pressing the hotkey again. New centerlines will be created based on the new key points you add and the existing key points you selected.

    In the add-point mode, after clicking a new location to add a new key point, you can drag the image to observe the vessel from another direction, then the casted ray will be shown and you can change the newly added key point location in the same way as mentioned in the section "Move a key point" above. In short, Shift + click to change the location to the hovered location on the casted ray, as shown below:

    Pay attention to the order of clicking

    New centerlines will be created based on the order of your clicks on new locations and existing key points.

    Existing centerlines may be automatically split

    During the add-point mode, if you clicked some existing key points that are not the endpoints of existing centerlines, then those existing centerlines will be split into several centerlines based on the clicked key points. This is because the software defines individual centerlines by bifurcations.

    You can form a loop

    • You cannot consecutively click the same location (the key point will disappear or deselected).
    • Still, you can click the same location as long as you do not click it twice consecutively. Therefore, you can create a centerline loop. This is useful, for example, for tracing the centerline of circle of Willis.

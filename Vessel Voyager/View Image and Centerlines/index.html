    View Image and Centerlines

    Image

    Once an image file is opened, you can observe the 3D image in the middle window (called the 3D window). The image is shown in the maximum intensity projection (MIP) mode, that is, a larger pixel value corresponds to a larger brightness.

    To hide or show the 3D image, use the hotkey Ctrl + Shift + V. This is useful if you want to only observe the centerlines more clearly.

    Histogram Window

    The intensity histogram window is in the lower left corner of the window (shown below). This is particularly useful for enhancing the visibility of certain (e.g., distal) vessels. It may even be useful for observing the vessels on black-blood images.

    The histogram shows the pixel intensity distribution of the opened image, after clipping negative intensities to 0. The x-axis is the intensity value.

    The red line defines the mapping between pixel intensities and brightness in the MIP view. The y-axis is the brightness (0-1). By default, it is just a straight line from \((0, 0)\) to \((\text{max_intensity}, 1)\), which means the intensity 0 corresponds to brightness 0 (transparent), and the max intensity corresponds to brightness 1 (max brightness).

    The red line's shape is controlled by red key points. You can change the line shape by:

    • Drag a key point to move it
    • Drag starting from any location on the red line to add a new key point and move it.
    • Right-click a key point (except for the two endpoints) to delete it.

    Note that the two endpoints' x coordinates cannot be changed.

    Once you release the mouse button after dragging or right-clicking, new mapping will be calculated based on the red line shape to change the pixel brightness. This process takes about 2 seconds. Once it is done, you can observe the effect by moving the mouse into the 3D window:

    Each shown centerline has two parts: a curve and several key points that defines the curve, like this:

    The number of key points must be at least 2. If the number is smaller than 4, then the curve is piecewise linear (not smooth); otherwise, the curve is smooth (calculated by cubic spline interpolation based on all key points).

    Color

    The color of the centerline (including the curve and key points) is determined by its vessel type. The correspondences between colors and types are shown in the labeling table on the right panel:

    For example, the figure above shows that the centerline with the type ICA_L (left internal carotid artery) is in orange.

    Some artery like ICA has two types, i.e., left (L) and right (R) sides. The left and right side colors of the same artery are different in brightness (the right-side type is darker). This is very useful if you want to quickly check if the left and right sides of the same artery have been labeled correctly.

    There is a type "unassigned" (in green) for the centerlines that have no labeling information. It is also the default type if you add a new centerline.

    Hide

    You can hide or show certain types of centerlines. This is useful if you want to observe the image or certain types of centerlines more clearly.

    • To hide or show all centerlines, press Shift + V.
    • To hide or show the centerlines of a specific type, click the text of type in the labeling table.
    • To only show the centerlines of a specific type (hide all other centerlines), or show all centerlines, double-click the text of the type in the labeling table.

    The text of hidden types in the labeling table will be shown in dark gray. For example, the figure below shows that the centerlines with types ICA_L or BA are hidden.

    3D Navigation

    You can observe the 3D image and/or centerlines from different directions and scales. There are two typical navigation modes: arcball and fly. We currently support the arcball mode; the fly mode will be supported in the future.

    Arcball mode: - Left-drag: orbits the view around its center point. - Right-drag or scroll: zoom in or out. - Shift + left-drag: translate the center point. - Shift + right-drag: change the field of view (FOV).
